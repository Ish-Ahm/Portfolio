AI Learning Assistant

For my graduation project, I designed and built a Socratic AI Learning Assistant chatbot with two distinct personas, Robin and Gram, tailored to university coursework in different university subjects for a performance comparison study. Both personas run on the same underlying system but are shaped by different characteristics and knowledge bases suited to their subject, and rather than giving direct answers, they use a guided, questioning approach intended to support genuine learning over quick fixes.

The system runs entirely locally, using Ollama open source models, ChromaDB for vector storage of the dataset, and uses an Open WebUI front end for the user interface. It is grounded in a retrieval-augmented generation pipeline built around each course's own knowledge base, specifically the university's own course materials like lectures and examinations.
